Dip-and-Ride Sniper: a pump.fun paper-trading bot that risks a small fixed stake per coin only after buyers prove themselves (price up 10% from first seen, real SOL in the curve), then exits fast with a hard stop, a take-profit ladder, a trailing stop and a time limit. One buy per coin, chunked sells, fully deterministic.

## Run it

```sh
node main.ts
```
